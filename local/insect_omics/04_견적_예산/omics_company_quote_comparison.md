## 5. 교수님 보고용 결론

- 기존 NICEM Full 견적은 20샘플 기준 3,908만원, VAT 별도이며 단백체·대사체·지질체·타깃 분석이 모두 포함된 원스톱 구조임.
- 공개 단가가 확인되는 민간업체는 이바이오젠 단백체 서비스가 가장 명확하지만, 해당 공개가는 human/mouse 조건이라 곤충 시료에는 그대로 적용하면 안 됨.
- POCUS/서린바이오-바질바이오텍은 NICEM Full과 유사한 원스톱 후보이나 공개 단가가 없어 실제 견적 문의가 필요함.
- 오믹스AI와 Bertis는 단백체 품질 강화형 후보, HMELAB은 대사체·지질체 분리 발주 후보로 보는 것이 합리적임.

## 6. 견적 문의 시 보내야 할 핵심 조건

| 항목 | 문의 내용 |
|---|---|
| 시료 | 곤충 조직/분말, 종명, 생물학적 반복수, 보관 상태 |
| 단백체 | label-free DDA 또는 DIA-LFQ, custom DB 검색 가능 여부, raw data 제공 여부 |
| 대사체 | positive/negative untargeted LC-MS/MS, annotation level, Compound Discoverer/MS-DIAL 등 분석 툴 |
| 지질체 | positive/negative lipidomics, lipid class coverage, MS/MS annotation 여부 |
| targeted | SCFA, amino acid, MRM 패널 가능 여부와 표준품 포함 여부 |
| 산출물 | raw file, peak table, protein/metabolite/lipid annotation, 통계, GO/KEGG/pathway 분석 |
| 비용 | 샘플당 단가, 셋업비, 데이터 분석비, batch 수, VAT 포함 여부 |
| 일정 | QC 이후 TAT, 샘플 수 증가 시 일정 |
