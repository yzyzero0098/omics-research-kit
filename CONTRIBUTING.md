# Contributing

This repository is a public research-automation index for omics workflows.
Contributions should make the notes easier to reuse, audit, or adapt.

## Good Contributions

- add official documentation links for a tool or file format
- improve a pipeline note with versioned commands
- add a minimal synthetic example
- clarify when a workflow applies to microbiome, shotgun, transcriptome, or proteome data
- report broken links or outdated commands

## Please Do Not Add

- private raw data
- patient-level or sample-identifiable metadata
- paid papers, PDFs, slide decks, or draft manuscripts
- large binary outputs or vendor databases
- credentials, tokens, or institution-only paths

## Pull Request Checklist

1. Keep the contribution small and reviewable.
2. Prefer official documentation or peer-reviewed references.
3. Use synthetic examples when demonstrating a command.
4. Confirm no private data or large artifacts are staged.
5. Explain which workflow area the change improves.
